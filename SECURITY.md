# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities via public GitHub Issues.

Instead, use [GitHub Security Advisories](https://github.com/haraig/zaas/security/advisories/new) to report a vulnerability privately.

Include as much detail as possible:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (optional)

You can expect an acknowledgement within 48 hours and a resolution or status update within 14 days.

## Supported Versions

Only the latest release is actively maintained and receives security fixes.
